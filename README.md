# kd-board

Feste Regeln für dieses Dashboard:

1. Für jeden gehaltenen Coin müssen alle Kursdaten verfügbar sein: von 1 Minute bis 1 Monat, zurück bis zum ersten Kurs (Dino-Marke).
2. Kommt ein neuer Coin dazu, gilt das automatisch. Keine Sonderbehandlung einzelner Coins im Code: Kraken-Paar eintragen, die tiefe Historie wird über das Binance-Symbol von selbst versucht.
3. Schätzungen und Näherungen sind in der Oberfläche als solche gekennzeichnet.
4. Keine Schlüssel oder Geheimnisse in diesem Repo.
